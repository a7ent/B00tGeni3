BUG FOUND AND FIXED
  The line after a red warning started at the column where the warning ended (run 4,
  p8c-nvram-confirm). Cause: "\n" inside a %s argument is not turned into CR+LF by Print.
  Fixed in build 2; p8c-b2-nvram-confirm shows the page correct.

DEVIATION FROM THE SPEC
  The spec names ResetNvramEntry and ToggleSipEntry. In 1.0.8 those are drivers that register picker
  entries and need the picker's context, so they cannot be started as tools. The tool starts
  CleanNvram.efi, CsrUtil.efi (argument "toggle") and OpenShell.efi with LoadImage/StartImage.
  CleanNvram.efi does not preserve firmware boot entries; the confirm page says so.
