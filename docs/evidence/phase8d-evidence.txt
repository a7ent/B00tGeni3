HOW THE SAVE WORKS
  The tool finds the single <key>boot-args</key> in the raw file, requires the <string> after it to be exactly
  the text OpenCore's parser reports, and replaces only that text in a copy. It then runs the unchanged Phase 5
  pre-flight on the copy, parses the copy again to confirm boot-args and serial, and writes it with the
  unchanged Phase 4 swap (backup, temp file, verify, rename). It refuses if the key is missing, repeated, or
  the value has escaped characters. The typed line does not accept < > &.
